# hit-song-prediction
Decoding Hit Songs: Structural Trends, Audio Patterns, and Repetition Analysis Using Machine Learning

Sprint 1 (Week 1): Data and features
Choose the market and define the hit label (e.g. top 40 within 12 weeks).
Download and join the datasets
Build the audio, structure and repetition features.
Output: one clean feature table with labels.
Sprint 2 (Week 2): Hit prediction
Time-based split by release year.
Baselines, then random forest and gradient boosting.
Output: trained hit model and a results table.
Sprint 3 (Week 3): Recommendation and mashups
Song embeddings and nearest-neighbor recommender.
Rule-based mashup scorer (key, tempo, energy)
Output: both models with evaluation metrics.
Sprint 4 (Week 4): Integration and delivery
Combine the three modules in a simple demo app (Streamlit or Gradio).
Write the report (method, results, limitations) and clean up the repo.
Output: working demo, report and reproducible repo.
